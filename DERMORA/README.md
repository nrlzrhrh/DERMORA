# DERMORA — Skincare Information & Recommendation System

A deployable static HTML/CSS/JavaScript prototype.

## Files
- `index.html` — page structure
- `style.css` — visual styling
- `script.js` — interactions, localStorage, recommendation rules and chatbot
- `.nojekyll` — GitHub Pages compatibility

## Demo accounts
- User: `user@demo.com` / `1234`
- Admin: `admin@dermora.com` / `admin123`

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local server.

No PHP, database, API key, or build step is required for this prototype.
